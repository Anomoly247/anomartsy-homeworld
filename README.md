## 🎨 The AO ALIVE Living Design Standard

All pages across this repository strictly enforce the **AO ALIVE Living Design Standard**, superseding legacy palettes and static web layouts.

### 1. Palette Tokens
* **AO Cyan (`#00eaff`):** Active status / Primary accent / Pixel & Explorer signatures
* **AO Magenta (`#ff00c8`):** In-Build status / Energy signature / Dot signature
* **AO Gold (`#d8ae55`):** Planned status / Card borders / Prestige rules
* **Homeworld Void (`#04040a`):** Deep ground background
* **Surface Panel (`#141423`):** Glassmorphic raised surfaces

### 2. Motion & Breathing Loops
To reflect a living, breathing celestial environment, elements use un-synchronized, staggered animation periods:
* **House 01 (Pixel & Dot / Anom's Corner):** `3.2s` breathing loop
* **House 02 (The Library & Security):** `3.6s` breathing loop
* **House 03 (District B Arcade & Mood Buddies):** `3.9s` breathing loop
* **House 04 (The Sanctuary):** `4.1s` breathing loop

### 3. Visual Signatures
* **Glass Navigation HUD:** `backdrop-filter: blur(18px)` with a 135° white gradient overlay (`rgba(255,255,255,0.12)` to `0.04`).
* **Three-Color Pulse Ring:** Stacked hero glows at `18px` (Cyan), `36px` (Magenta), and `54px` (Gold).
* **Typography:** `Space Mono` (Display / Headlines), `Inter` (Body text), and `JetBrains Mono` (Technical HUD tags with `0.2em–0.3em` letter-spacing).
